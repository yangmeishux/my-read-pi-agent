# book-insights

从书中挖掘深刻洞见，输出可落地的启发清单。

## 与 book-summary 的区别

- `book-summary` 是全书概览（广度）
- `book-insights` 是深度挖掘（深度），聚焦反常识观点和个人启发

## 执行流程

1. 使用 `book-query` 检索书中的反常识观点、实验、案例
2. 识别作者的核心洞见（与常识相悖的）
3. 将洞见转化为可落地的行动启发

## 输出结构

### 深刻洞见（3-5 条）

每条格式：
```
#### 洞见 N：[标题]

**反常识点**：一句话说明为什么反直觉
**书中论证**：作者用什么证据支撑（带引用）
**我的理解**：用自己的话重述

---
```

### 启发清单（5-8 条）

每条格式：
```
- **[启发标题]**：[具体行动或场景]
  - 来源：[章节名]
```

启发必须满足：
- 能落地到具体行动（不是"多思考"而是"每天花 10 分钟写反思日记"）
- 有明确场景（"在 XX 情况下可以 YY"）

## 输出

写入 `workspace/<slug>/insights.md`。

## 禁用

- 不许泛泛而谈（"让我们学会思考"）
- 不许重复 summary 的内容
- 不许虚构作者未提及的观点
