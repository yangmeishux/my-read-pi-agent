# 阅读标注：聪明人的个人成长

## 1. 适用目的

默认读者：第一次通读，要拿到「真实 / 爱 / 能量」这套决策操作系统，并知道如何试 30 天，而不是收集鸡汤句子。

## 2. 核心骨架（必精读）

1. **用五条标准筛原则；只留下真实、爱、能量三条不可再分基础原则** — [引言]
2. **真实 = 以现实为检验；爱 = 选择联结；能量 = 责任到行动的链条** — [第1–3章]
3. **原则要变成习惯：30 天尝试，而不是立志永久改变** — [第8章]

衍生原则（一体 / 主导 / 勇气 / 清醒自主）是组合，不是第三套平行真理——懂 1–3 章后再读，否则会觉得七条在并列堆砌。

## 3. 章节读法表

| 章节 | 标签 | 理由 | 读到什么算过关 |
|------|------|------|----------------|
| 引言 | 精读 | 问题定义 + 五条筛选标准 + 七原则关系图，后面全靠它 | 能说出为什么是这三条而不是别的成功学条目 |
| 第1章 真实 | 精读 | 全书第一根支柱；觉察→接纳是后续章的前提 | 能举一件自己正在否认的事实，并写下「现实检验」 |
| 第2章 爱 | 带着问题读 | 定义关键（选择联结）；铺陈与故事可扫 | 能把「爱」从情绪改写为可选择的行为 |
| 第3章 能量 | 精读 | 责任/欲望/行动链条可操作；作者入狱经历服务这条链，细节可略 | 能画出「责任→欲望→选择→专注→行动→自律」并标自己断在哪一环 |
| 第4章 一体 | 略读 | 真实+爱的组合，增量主要是展开六要素 | 知道一体 = 真实+爱，不必背六要素 |
| 第5章 主导 | 带着问题读 | 真实+能量；对「知道但不做」的人有用 | 能指出自己生活中指挥权交给了谁 |
| 第6章 勇气 | 带着问题读 | 「恐惧是导航」是高价值句；其余修辞可扫 | 能列出一件害怕但必须面对的事，并拆成小步 |
| 第7章 清醒自主 | 略读 | 三条基础原则的汇总，精读引言+1–3章后这里多为重复 | 能用一句话定义清醒自主 |
| 第8章 习惯 | 精读 | 把原则落到 30 天实验，否则前七章停在态度 | 能选定一个 30 天尝试并写下开始日 |
| 第9章 职业 | 带着问题读 | 应用章；正在纠结职业再精读 | 能问「职业是否服务真实自我」 |
| 第10章 金钱 | 带着问题读 | 索取 vs 贡献是可迁移判断；理财技巧不是本书强项 | 能判断自己当前是索取型还是贡献型立场 |
| 第11章 健康 | 可跳过 | 健康信息易过时，且用原则复述多于新方法 | 无（默认路径）；有健康决策时再翻 |
| 第12章 关系 | 带着问题读 | 与第2章高度相关；关系困境时再深读 | 能把一段关系对照「坦诚/真实联结」 |
| 第13章 心灵 | 可跳过 | 信仰/意义高度个人；中文版此处还有审改痕迹，不宜当精确文本 | 无（默认路径） |
| 后记 | 略读 | 收束态度，无新工具 | 回到「开放、爱、能量」三词即可 |

## 4. 可略读 / 可跳过

- **各章中重复的原则定义**：第1–3章读透后，第4、7章大量段落对骨架无增量。
- **励志叙事的过长展开**（被捕、后院体验等）：保留「它在证明哪条原则」，故事本身可扫。
- **第11章健康、第13章心灵**：应用示例，不是新原则；后者译本还有引用替换，精读风险高。
- **「1000 年依旧有用」类绝对句**：当作作者自信，不当作可证伪结论。

## 5. 时间盒读法

- **30 分钟**：引言五条标准 + 第1章「现实是检验标准」+ 第8章「30天尝试」规则。合上书后选定一个 30 天实验。
- **2 小时**：引言 + 第1、3章 + 第8章 + 第6章「恐惧是导航」小节。
- **精读路径**：引言 → 第1–3章（第2章可较快）→ 第8章立刻开实验 → 按当前困境选第5/6/9/10/12 章之一，不平均精读应用章。

## 6. 按目的分流

| 目的 | 多读 | 可砍 |
|------|------|------|
| 建立决策原则 | 引言、第1–3、8章 | 第11、13章 |
| 克服拖延/恐惧 | 第3、5、6、8章 | 第4、7、13章 |
| 职业/金钱决策 | 第1、9、10章 | 第11章 |
| 关系问题 | 第2、12章（先读第1章真实） | 第11、13章 |
