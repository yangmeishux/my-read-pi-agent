# 阅读标注：如何快速了解一个行业

## 1. 适用目的

默认读者：第一次通读，要拿到一套能套到任意行业的分析骨架，而不是背资讯源。

## 2. 核心骨架（必精读）

1. **用渗透率而不是营收斜率判断行业阶段** — [第1章]
2. **七维分析是「按阶段选用的镜头」，不是每章都要做满的清单** — [第2–8章的用法，精读第1章里的对应关系即可]
3. **研究的价值是制造信息差；普通人主攻深度差** — [第10章]

不读第 1、10 章，等于没读这本书。

## 3. 章节读法表

| 章节 | 标签 | 理由 | 读到什么算过关 |
|------|------|------|----------------|
| 前言 | 略读 | 动机与「为赚钱而写」不改变框架；扫过即可 | 知道本书目标是「快速看懂行业」 |
| 第1章 主框架 | 精读 | 全书坐标系：生命周期 + 渗透率阈值 + 不同阶段研究重点 | 能用渗透率公式判断一个行业处于哪一阶段，并说出该阶段该看什么 |
| 第2章 可行性 | 带着问题读 | 七维之一；只在「导入→成长」决策时需要抠 | 能判断商业模式是否「需求真、能赚钱、可复制」 |
| 第3章 规模性 | 带着问题读 | TAM/SAM/SOM 是高频武器，但公式短、例子可跳 | 听到「万亿市场」能立刻追问三层口径 |
| 第4章 防守性 | 带着问题读 | 护城河分类有用；案例可扫 | 能说出壁垒类型，并问「能否被砸钱绕开」 |
| 第5章 盈利性 | 带着问题读 | 集中度与利润分配，做投资/入职时再深挖 | 知道该看产业链哪一段更赚钱 |
| 第6章 估值 | 带着问题读 | 与阶段绑定；不做估值可整章降为略读 | 知道不同阶段不能用同一套估值 |
| 第7章 外部因素 | 略读 | PEST 变体，增量有限，多数读者已知 | 记住「政治/经济/文化/技术」四格，用时再翻 |
| 第8章 景气度 | 带着问题读 | 看指标与上下游；实操时才有用 | 能列出该行业 3 个领先指标 |
| 第9章 实战 | 带着问题读 | 新能源是习题不是新理论；已懂框架则当对照作业 | 能自己按 1–8 章把一个行业走一遍 |
| 第10章 研究方法 | 精读 | 把「知道很多」改写成「信息差」；深度差是给普通人的结论 | 能回答「我比市场多知道什么」 |
| 第11章 研究进阶 | 带着问题读 | SCQR / 资讯料理法对写汇报有用，对「看懂行业」非必须 | 能用情景-冲突-问题-解答写一页结论 |
| 第12章 研究工具 | 当附录查 | 资讯源清单会过时，通读收益低 | 需要找数据时再打开对应小节 |
| 第13章 研究新时代 | 可跳过 | 生成式 AI 用法时效短，对框架无增量 | 无；用自己的 AI 工作流即可 |
| 结语 | 略读 | 强调练习，无新概念 | 接受「框架要靠案例练」即可 |

## 4. 可略读 / 可跳过

- **前言里的自我经历与「写得最认真」**：对抓住骨架无增量。标注者判断，非作者声明可跳。
- **第7章外部因素**：与常见 PEST 高度重叠，精读机会成本高。
- **第12章整章名录**：统计机构、数据库、社群——当通讯录，不要当正文。
- **第13章 AI 研究**：产品与提示会过时；与第1、10章主张无关。
- **第9章中过长的行业背景铺陈**：只保留「框架是如何被填进去的」那些段落。

## 5. 时间盒读法

- **30 分钟**：第1章渗透率与阶段对照 + 第10章三种信息差（尤其深度差）。合上书后用一句话判断自己所在行业的阶段。
- **2 小时**：30 分钟路径 + 第3章 TAM/SAM/SOM + 第4章护城河可绕开性 + 扫第9章目录看框架如何填空。
- **精读路径**：第1章 → 第10章 → 按自己行业选读第2–8章中 2–3 维 → 用第9章当答题卡自己写一版（不必抄新能源）。

## 6. 按目的分流

| 目的 | 多读 | 可砍 |
|------|------|------|
| 投资/看赛道 | 第1、3、4、5、6、8、10章 | 第12、13章；第11章可后置 |
| 转行/入职某行业 | 第1、2、5、10章 + 第9章当模板 | 估值章、工具名录 |
| 写行业汇报 | 第10、11章 + 第1章 | 第13章 |
