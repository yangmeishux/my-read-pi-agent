# 读书智能体使用指南

## 快速开始

### 1. 安装依赖

```bash
# Node 依赖（Pi Agent）
npm install

# Python 依赖（解析 + 向量）
pip install -r requirements.txt
```

### 2. 配置 API Key

```bash
cp .env.example .env
# 编辑 .env，填入 DashScope API Key
```

### 3. 起一本新书

```bash
# 方式 1：直接解析文件
python scripts/ingest.py ~/Downloads/思考快与慢.pdf

# 方式 2：先建工作区，再解析
python scripts/new_book.py "思考快与慢" --author "丹尼尔·卡尼曼" --file ~/Downloads/思考快与慢.pdf
python scripts/ingest.py ~/Downloads/思考快与慢.pdf --slug 思考快与慢
```

### 4. 启动 Pi Agent

```bash
npm run pi
```

### 5. 在 Pi 对话中执行流程

```
/skill:book-ingest
/skill:book-summary
/skill:book-insights
/skill:book-review-search
/skill:reading-report
```

## 完整流程说明

### Phase 1：文档解析（book-ingest）

**输入**：PDF/EPUB/TXT 文件路径

**过程**：
1. 检测文件格式
2. 解析为 Markdown（PDF 用 marker-pdf，EPUB 用 ebooklib）
3. 按章节标题切块（每 chunk ≤ 2000 字符）
4. 构建 Chroma 向量索引（DashScope text-embedding-v3）

**输出**：
- `library/parsed/<slug>.md` — 解析后的 Markdown
- `library/index/<slug>/` — Chroma 索引
- `workspace/<slug>/book.yaml` — 书籍元信息
- `workspace/<slug>/refs.json` — chunk 索引

**验证**：
```bash
cat workspace/<slug>/book.yaml
# 应看到 chunk_count > 10
```

### Phase 2：并行分析（summary / insights / external-reviews）

三个 Skill 可以并行执行：

#### book-summary（全书总结）

**输出**：`workspace/<slug>/summary.md`

**必含章节**：
1. 一句话论点
2. 三句话摘要
3. 章节地图
4. 关键概念
5. 论证链
6. 深刻洞见
7. 启发清单
8. 争议与局限
9. 延伸阅读
10. 原文引用（≥5 条）

#### book-insights（洞见与启发）

**输出**：`workspace/<slug>/insights.md`

**内容**：
- 3-5 条深刻洞见（反常识观点）
- 5-8 条可落地启发（具体行动）

#### book-review-search（外部书评）

**输出**：`workspace/<slug>/external-reviews.md`

**搜索源**：
- 豆瓣评分 + 热门书评
- Goodreads 评分 + top reviews
- 维基百科背景
- 知乎讨论

### Phase 3：合并报告（reading-report）

**输入**：summary.md + insights.md + external-reviews.md

**输出**：`workspace/<slug>/report.md`

**过程**：
- 确定性导出（不改写论证）
- 统一引用格式为 `[章节名]`
- 添加目录（TOC）
- 末尾附引用索引表

### Phase 4：门禁检查（quality-reviewer）

**检查项**：
- 引用数 ≥ 5
- 无禁用词
- 10 个必含章节全部存在
- 启发可落地
- LLM 评分 ≥ 9

**未通过**：
- 回退到 summary/insights 修改
- 最多重试 3 次
- 超限走 best_effort

## 常见问题

### Q: marker-pdf 首次运行很慢？

A: marker-pdf 首次运行会下载模型（约 2GB），需要网络。后续运行会快很多。

### Q: 解析质量不佳，chunk 数很少？

A: 检查 `library/parsed/<slug>.md`，看解析后的 Markdown 是否正常。可能是 PDF 排版问题（扫描版、图片版）。可以尝试用 pymupdf4llm 回退。

### Q: 向量检索结果不准确？

A: 可以调整 `scripts/query.py` 中的检索策略：
- 增加 `top_k` 参数
- 调整 RRF 常数 k（默认 60）
- 检查 embedding 模型是否正确加载

### Q: 门禁评分低于 9？

A: 查看 `quality-reviewer` 的反馈，通常是：
- 引用数不足 → 增加原文引用
- 禁用词出现 → 替换为自然表达
- 启发不具体 → 细化为可行动的步骤
